## 各批共同要求

- 新写入复用领域规则，多表事务与幂等回执原子提交；来源修订涵盖实际输入与数据世代。
- 注册完整输入/输出契约及权限依赖；长正文支持完整读取，不将截断的内容用于生成或保存。
- Web 与 MCP 读取相同正式记录；模型结果先校验再提交，外部协作不启用服务端模型。
- 验证正常流程、无效输入、权限、版本冲突、重复提交、断线恢复与备份恢复。
- 完成类型检查、lint、相关集成/E2E、全量回归、生产构建及构建追踪检查；扩展真实客户端与示例验收。

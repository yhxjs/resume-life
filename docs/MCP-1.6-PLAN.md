- [x] 7. 协议与客户端：扩展真实 Host 的工具发现、结构化错误、文件和重连验收；评估官方 Tasks 扩展适配并保留原调用兼容性。

## 不变量

- SQL 归属共享领域模块，多表写入使用事务；输入输出有界；不泄露未授权正文或模型凭证。
- 新能力仍使用本机 stdio；没有远程 HTTP 接入。
- 已发布版本、投递快照与正式证据保持原语义。写入复用幂等回执、来源修订及恢复世代；不自动重试已认领模型调用。
- 复用本地 Next.js 文档规定的 API；完成契约、领域/网页回归、SDK/Host 和跨平台验证。
- 不把单元模拟、CI 配置或旧提交结果当作本轮完整验收。

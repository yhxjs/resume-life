# 知识库探索的自定义 CLI / SDK 客户端

在项目详情选择“扫描本地代码仓库”，再选择“自定义 CLI / SDK”。填写可执行程序和参数即可扫描，也可命名保存为客户端配置，在同一浏览器中切换使用（最多 20 个）。

在同一次扫描弹窗中，切换到 Auto、Codex 或 Claude 再返回自定义时，会保留所选配置、名称、可执行程序和命令参数，包括尚未保存的修改。关闭弹窗后未保存草稿会重置；已保存配置可在下次打开时重新选择。

| 用法 | 可执行程序 | 命令参数（JSON 数组） |
| --- | --- | --- |
| Node.js SDK 包装脚本 | `node` | `["D:/tools/sdk-client.mjs"]` |
| Python SDK 包装脚本 | `python` | `["D:/tools/sdk_client.py"]` |
| 其他客户端原生程序 | `D:/tools/client.exe` | 填写该客户端支持的非交互、纯文本参数；无参数填 `[]` |

可执行程序可以是服务进程 PATH 中的命令名称，也可以是宿主机绝对路径。Windows 按查找顺序选择首个支持的 `.exe`、`.com`、`.cmd` 或 `.bat`，不会让后面的原生程序覆盖前面的同名批处理客户端。路径有空格时也不要加外层引号；参数中每一项独立传递，不按 shell 命令行拆分。程序在空临时目录中运行，因此包装脚本和配置文件应使用绝对路径。

“最终命令预览”随工具选择、命令、参数或已保存配置切换实时更新。预览展示完整程序及参数，提示词统一显示为 `stdin: {{PROMPT}}`；引号和转义仅用于区分参数，预览不作为 shell 脚本执行。实际提示词仍只走标准输入，预览占位符不会进入参数。Auto 在环境检测完成后显示当前推荐客户端；自定义参数无效时显示原因，不保留旧预览。

## 客户端输入输出约定

- 从标准输入读取完整 UTF-8 提示词，直到 EOF；不支持把提示词替换到命令行参数的占位符。
- 使用客户端已有登录或服务进程的环境变量完成认证。密钥应由客户端管理，不要保存在命令参数中。
- 开启非交互模式，在标准输出返回模型回复正文，进度日志写入标准错误；正常完成退出码为 0。
- SDK 包装脚本负责把 SDK 响应中的模型正文写入标准输出，不输出 SDK 响应外壳、JSONL 事件或工具调用协议。
- 提示词会要求相应 JSON 结构：扫描返回八字段项目总结，多仓库预检返回 `isRelated` 和 `reason`。预检和扫描使用同一客户端配置。
- 自定义客户端需自行关闭文件、命令、网络搜索和外部插件等模型工具。应用只传入过滤后的源码材料，但空临时目录不构成操作系统权限沙盒，不能替第三方程序强制禁用工具。

例如，Node.js 包装脚本应先收集 `process.stdin` 的全部文本，将其传给所用 SDK 的文本分析接口，再用 `process.stdout.write` 写出返回的模型正文。SDK 的选择、认证和模型设置留在自己的脚本中，无需改动本应用。

程序查找与文件、执行权限检查共用五秒截止时间；取消或超时后立即停止等待，迟到的文件检查不会启动客户端或继续后续读取。扫描继续使用现有的源码过滤、输出校验、五分钟总截止时间、取消进程树和并发限制。多仓库预检给客户端 15 秒；自定义客户端失败时返回无法确认关联，由界面要求确认是否继续，不自动换用其他客户端或应用内模型。生成结果仍先进入工作台草稿，确认后才保存。

Windows 的 `.cmd` / `.bat` 经 `cmd.exe` 启动，所有固定参数和路径均逐项引用。包含 `%`、双引号、换行或 NUL，或以反斜杠结尾的批处理参数会在启动前被拒绝；末尾反斜杠可能在批处理转发给原生程序时合并或改写参数。目录参数可改用正斜杠（如 `C:/SDK config/`）；必须保留原参数时，使用原生程序，或以 `node` / `python` 直接运行 SDK 包装脚本。批处理命令和参数还受 8,000 字符总预算约束。

客户端配置保存在当前浏览器，包含程序路径与固定参数；不写入项目或业务备份。可单独移除已保存客户端，设置页“清除本机敏感副本”和退出登录也会清除全部客户端配置。重新打开扫描弹窗后需明确选择已保存配置，不自动执行它。

- `npm run build` 使用独立测试数据目录通过；`npm run check:build-trace` 检查 162 份打包清单通过，并同时排除默认和自定义数据目录。
- `npm run benchmark:mcp`：608000 个 UTF-16 单位正文完整还原、100 次网页并发写入后的数据一致；分段读取 P95 32.11 ms，5000 条日志中的查询 P95 4.05 ms。

Windows／Linux CI 矩阵已更新，本机实际执行环境为 Windows。更新代码后重启网页与 MCP 进程，接入步骤见 [MCP 文档](MCP.md)，可运行示例见 [workflow.mjs](../examples/mcp/workflow.mjs)。

## 审查修复（2026-11-25）

- 复习历史的每条回答提供 `review_attempt` 完整读取入口；精确提交提供携带原 UUID 的 `review_submission` 入口，两者分别沿用对应读取权限。
- 诊断快照或采纳记录损坏时，完整读取保留被隐藏的原报告；网页继续将损坏诊断标记为不可采纳。
- 复习卡完整读取沿用摘要中的指定时区，避免新卡日期因服务器时区而变化。

新增 6 项回归用例覆盖原报告保留、长回答分页与完整还原、权限隔离以及日期线两侧的时区一致性。隔离 stdio MCP 实测完整读回三条各 20,000 字的回答，并核对按提交编号读取的结果。

修复后的固定版本验收：全量 `npm test -- --silent --maxWorkers=4 --reporter=dot` 的 623 个测试文件通过，14,318 项通过、1 项跳过；相关网页 E2E 的 6 个文件共 23 项通过。真实 Codex MCP 检查、类型检查、lint、生产构建及 162 份构建追踪清单检查均通过。本轮复审未发现新的可复现问题。

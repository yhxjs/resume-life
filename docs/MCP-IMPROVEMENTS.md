## MCP 1.2：训练与资料创作（2026-11-25）

| 计划 | 已验证的行为 |
| --- | --- |
| 保存练习作答 | 外部评分与网页共用作答事务。网页抢先保存返回冲突；登记复习卡失败时不留下原答或回执；普通题和追练题沿用不同入卡规则。 |
| 从题库发起练习 | 分页查题及分类、按指定顺序建场、作答、收藏、复习并在重连后核对；旧题库版本或重复选题不创建半成品。 |
| 编辑自我介绍 | 完整新句子生成可分页的预览；保存绑定该版原稿及具体提案。验证旧令牌、跨版、改稿、网页竞争及损坏原稿均不会被覆盖。 |
| 录入项目材料 | 创建和追加只写一次；长文本（含换行与非 BMP 字符）从网页和 MCP 分段读回一致；不允许指定路径或文件提取来源。 |
| 主持单场模拟面试 | 明确指定简历发布版、重连继续回合、自然或提前结束、按原答汇总一次报告；两个独立 stdio 进程不能同时推进同一回合。 |

## 训练功能持续审查修复（2026-11-25）

- 挖掘报告允许六项事实文本中的未知项为空；保留必填字段，继续拒绝无有效事实或待核实事项的报告。
- 介绍插入、删除或移动后，未改写原句保留原点评；重复原句按出现顺序各匹配一次，新增或改写正文不沿用不对应的点评。
- 项目修订纳入全部材料正文和表格来源；未展示正文、来源标记及网页删除均使旧令牌失效，项目与材料在同一事务读取。
- 练习评分上下文复用网页的 DOCX 表格来源判读规则，摘要和完整分段读取保持一致。
- 网页题库重练沿用原场次选题、方向与 JD，兼容无背景、跨方向和原题库条目删除；模型等待期间源资料变化拒绝保存，完整选题超预算整次拒绝。
- 复制题库原题保留首尾空白、换行和字面文本；生成题目继续在解析阶段整理格式。
- 新建及重练拒绝无有效题干的选题，整场不留下半成品，保留原题库和已保存场次。
- 评分修订绑定完整规则；规则变化而题目及材料相同时，旧上下文的新评分提交也返回冲突。

新增 22 项回归覆盖以上行为、旧令牌、同毫秒改动、隐藏材料、DOCX 来源、跨进程写入、原题保真及无效选题。最后一处评分规则修复后，MCP 与相关网页练习的 7 个测试文件共 183 项通过；真实 Codex 客户端的重连、幂等、冲突和生产备份恢复通过。类型检查、lint、生产构建及 162 份构建清单检查通过，8 个相关网页 E2E 文件共 29 项通过；最终构建上的练习网页 2 项再次通过。

# 示例数据

这里的内容全部是虚构演示数据，不对应真实候选人、公司或职位。导入前请确认应用使用的是测试数据目录。

## 文本导入

可以把 `sample-resume.txt` 作为简历文本，把 `sample-jd.txt` 作为职位描述输入现有导入流程。AI 解析如果启用，只会产生待确认草稿；保存前请人工检查所有字段。

示例联系人使用 `example.com`，不能用于实际投递。

## MCP 协作示例

在仓库根目录运行 `npm run example:mcp`。示例自行创建临时目录，使用合成题库、简历和自我介绍；不会写入日常使用的数据目录或调用模型。除岗位准备和复盘外，[训练示例](mcp/training-workflow.mjs) 还演示选题作答、复习、确认介绍编辑、录入项目材料和重连继续单场面试。权限和参数见 [MCP 接入](../docs/MCP.md)。
